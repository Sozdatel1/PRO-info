# PRO-info 🌍

**PRO-info** — это универсальный веб-сервис, объединяющий в себе полезную информацию, интересные факты, календарь праздников, актуальные статьи, интерактивные карты и прогноз погоды. Все самое важное — на одной платформе.

---

## ✨ Основные возможности
*   **Погода:** Просмотр прогноза в реальном времени.
*   **Карты:** Интерактивный поиск локаций.
*   **Календарь:** Предстоящие праздники и события дня.
*   **Инфо-блок:** Статьи и подборки интересных фактов.

## 🚀 Технологии
В проекте использовались:
*   **Frontend:** HTML5, CSS3, JavaScript (или React/Vue)
*   **API:** OpenWeatherMap (погода), Google Maps API (карты)
*   **Backend:** Node.js / Python (если есть)
